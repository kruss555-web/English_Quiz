# English Quiz Bot — ежедневные тесты по английскому в Telegram-канале

Каждый день бот публикует в канал одну викторину (4 варианта) с заголовком вида
`🎯 B2 (Upper-Intermediate) · Grammar: Third Conditional`.
Если выбрать неверный ответ, Telegram сразу покажет пояснение; при верном ответе его можно открыть значком лампочки.

- Банк вопросов: `questions.json` (в комплекте 18 стартовых вопросов).
- Бот берёт вопросы в случайном порядке, без повторов до конца круга, потом перемешивает банк заново.
- Банк сам пополняется по ночам через Gemini API (бесплатный уровень) до `TARGET_SIZE` (по умолчанию 1000).
  Каждый новый вопрос проверяется вторым независимым запросом, а неоднозначные и дубликаты отбрасываются.
- Всё работает в GitHub Actions: сервер не нужен, платить не нужно.

## Настройка (один раз, ~10 минут)

**1. Бот и канал**
1. В Telegram откройте @BotFather → `/newbot` → скопируйте токен.
2. Создайте канал и дайте ему публичный `@username` (так проще всего).
3. Канал → Управление → Администраторы → добавьте своего бота с правом публиковать сообщения.

**2. Ключ Gemini**
Откройте https://aistudio.google.com → Get API key → скопируйте ключ. Карта не нужна.

**3. Репозиторий**
1. На github.com: New repository, **Public** (для публичных репозиториев Actions бесплатны).
2. Add file → Upload files → перетащите всё содержимое этой папки, включая папку `.github`.
3. Проверьте, что в репозитории есть файл `.github/workflows/bot.yml`. Если папка не загрузилась
   (она скрытая): Add file → Create new file, в имени введите `.github/workflows/bot.yml` и вставьте содержимое файла.

**4. Секреты**
Settings → Secrets and variables → Actions → New repository secret. Нужны три:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | `@username_канала` |
| `GEMINI_API_KEY` | ключ из AI Studio |

**5. Проверка**
Вкладка Actions → English Quiz Bot → Run workflow:
1. `action = post` → в канале должна появиться викторина.
2. `action = generate`, `count = 20` → в логе видно, сколько вопросов добавлено.

Дальше всё идёт само:
- каждый день в 09:00 UTC публикуется вопрос;
- каждую ночь в 02:30 UTC банк пополняется до `TARGET_SIZE`.
  Из-за лимитов бесплатного тарифа заполнение до 1000 займёт примерно 1–2 недели, пока в канале идут стартовые вопросы.

## Управление

| Что | Как |
|---|---|
| Вырастить банк дальше | Settings → Variables → `TARGET_SIZE` = 1500 (или запустите `generate` с нужным `count`) |
| Язык пояснений | Variable `EXPLANATION_LANG` (по умолчанию `Russian`, можно `English`) |
| Другая модель Gemini | Variable `GEMINI_MODEL` (по умолчанию `gemini-flash-latest`) |
| Время публикации | Измените `cron: "0 9 * * *"` в `.github/workflows/bot.yml` (время в UTC) |
| Свои вопросы | Добавьте объект в `questions.json` по образцу существующих (id уникальный) |
| Убрать плохой вопрос | Удалите его строку из `questions.json` |

## Если что-то не работает

- **Бот не публикует, в логе ошибка Telegram**: проверьте, что бот админ канала и что в `TELEGRAM_CHAT_ID` указан `@username` с `@`.
- **`Gemini API 404`**: имя модели устарело. Откройте AI Studio, посмотрите актуальное имя Flash-модели и задайте его в `GEMINI_MODEL`.
- **`429` / «остановка»**: исчерпан лимит бесплатного тарифа. Прогресс сохранён, генерация продолжится на следующую ночь.
- **Перенос строки в заголовке выглядит плохо**: в `common.py` замените `HEADER_SEP = "\n\n"` на `" | "`.
- **Расписание перестало срабатывать**: GitHub отключает расписания в публичном репозитории после 60 дней без активности.
  Бот ежедневно коммитит `state.json`, и это должно считаться активностью, но через пару месяцев стоит проверить вкладку Actions.
  Если запуски остановились, нажмите Enable workflow.
- Время запусков по расписанию может плавать: GitHub иногда запускает их с задержкой в несколько минут.

## Файлы

- `bot.py` — публикация одного вопроса и выбор следующего из очереди
- `generate.py` — генерация и проверка новых вопросов
- `common.py` — общие функции и проверка лимитов Telegram
- `questions.json` — банк вопросов
- `state.json` — очередь и номер круга (обновляется ботом)
- `.github/workflows/bot.yml` — расписание и ручной запуск
